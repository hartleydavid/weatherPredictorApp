# weatherPredictorApp
*The page currently is not predicting weather
as it is just pulling data from the WeatherAPI's database to show what the weather will be up to 300 days in advance.*

Web Application that will display the weather of a given date up to 300 days in advance. The page uses React.js as a framework
and uses Google Maps and WeatherAPI as API's that we get data from for the page to work. 

#Future Updates
Upon upgrading WeatherAPI's plan, pull the data from WeatherAPI's history API (Every specific date from 2010-2023) and predict the weather that way.
